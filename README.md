# 📖 Overview

Blog-Writing is a full-stack AI content generation platform that helps users create professional blog articles within seconds. Users simply provide a topic, and the AI generates structured, readable, and engaging blog content.

The project combines the **MERN Stack** for user management and application logic with a **Python AI backend** responsible for intelligent blog generation.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/mayankcharde/Blog-Writing.git

cd Blog-Writing
```

---

## Node Backend Setup

```bash
cd "BLOG WRITING AGENT/backend"

npm install

npm start
```

---

## Frontend Setup

```bash
cd "BLOG WRITING AGENT/frontend"

npm install

npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```

---

## Python AI Backend Setup

```bash
cd python-backend

pip install -r requirements.txt

python server.py
```

---

# 🔑 Environment Variables

Create a `.env` file inside the Node backend.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

AI_API_KEY=your_ai_api_key
```
